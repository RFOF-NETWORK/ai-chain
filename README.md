**AI‑Chain** ist eine souveräne, deterministische, auditierbare Blockchain‑Umgebung, die aus der
RFOF‑BOxChain‑Architektur hervorgeht und GoldenChain als interne Blockchain‑Komponente integriert.
Durch die Kombination entsteht RFOF‑GOLDEN: ein 0ms‑logikbasiertes, modular aufgebautes,
interdisziplinäres System, in dem Blöcke in BOxen und BOxen in Blöcken existieren.

### Dieses Repository enthält:

- die vollständige VM‑Architektur (vm_core, blockchain, fees, liquidity, wallet, viewer)
- die Token‑Module (AI, COIN, AIC‑LP)
- das ECCU‑System (VC.ecc, Safe, Fond, Fee‑Split 45/42/10/3)
- die interne & externe API
- die UI (HTML, JS, Charts)
- die Datenhaltung (chain.json, users.json, settings.json)
- die VC‑Integration (vm.VC)

Alle README.md‑Dateien in den Unterordnern sind kurz, fokussiert und technisch.
Diese Master‑README.md fasst alles zusammen.

---

### 1. Architekturüberblick

```
ai_chain/
│
├─ core/                  → VM‑Kern (blockchain, fees, vm_core)
├─ wallet/                → Wallet‑System
├─ liquidity/             → Liquidity‑Pool
├─ viewer/                → Chain‑ und Portfolio‑Viewer
├─ ECCU/                  → VC.ecc, Safe, Fond
├─ api/                   → interne & externe API
├─ scripts/               → UI‑Logik (ui.js, charts.js)
├─ data/                  → chain.json, users.json, settings.json
│
├─ ai_token.py            → AI‑Token
├─ coin_token.py          → COIN‑Token
├─ aiclptoken.py        → AIC‑LP‑Token
│
├─ index.html             → UI
├─ styles.css             → UI‑Styles
├─ ai-chain.py            → öffentliche Python‑Schnittstelle
├─ vm.VC                  → VC‑Kontext
└─ VC.ecc                 → ECCU‑Lizenz‑Modul
```

### 2. VM‑Kontext (vm.VC)

```
vm.VC
│
├── VM-Kontext
│     ├── blockchain = core/blockchain.py
│     ├── fees = core/fees.py
│     ├── wallet = wallet/wallet_system.py
│     ├── liquidity = liquidity/liquidity_pool.py
│     ├── viewer = viewer/chain_viewer.py
│     ├── smartcontracts = smartcontracts.py
│     └── chain_state = data/chain.json

├── Interner API-Bereich
│     ├── deposit = api/deposit.py

│     ├── marketprice = api/marketprice.py
│     ├── sync = api/sync.py
```
