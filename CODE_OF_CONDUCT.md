# Code of Conduct

Dieses Projekt folgt einem respektvollen, professionellen und konstruktiven Umgangston.

## Grundsätze

- Respekt gegenüber allen Mitwirkenden
- Keine Diskriminierung oder Belästigung
- Konstruktives Feedback statt persönlicher Angriffe
- Transparente Kommunikation

Verstöße können zur Sperrung führen.
